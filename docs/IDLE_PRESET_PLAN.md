# 无人时状态方案（IDLE 预设）v1.3
日期：2026-10-28

## 架构

- 现有 FSM 不改（跟人交互态）
- 新增 `PresetController`：维护 `currentState ∈ {S1,S2,S3A,S3B,S3C,IDLE}`
- 人出现立即中断，按当前状态走过渡表，切回 FSM

## 触发条件（统一用秒）

```
持续无人 <2s        → 忽略（视为遮挡/误检）
持续无人 2–5s       → 疑似离开，保持当前态
持续无人 >5s        → 进 preset 第 1 轮
持续有人 >0.3s      → 立即中断，走中断过渡表
```

## 关键参数

- 眼物理限位：yaw/pitch ±30°（EYE_MAX_DEG）
- 眼软件限幅：80% = **±24°**
- S1 眼 h 目标：**18–22°**（不超限）
- 颈 85%：yaw ±25.5°，pitch ±17°，roll ±12.75°
- 眼水平 max = ±24°；垂直 max = ±24° × 0.67 ≈ ±16°
- 思考头速 ≤8°/s，大转头 12–18°/s

### 权重→角度映射（连续无跳变）

```
w < 0.05           → 0°
0.05 ≤ w ≤ 0.25    → 线性映射到 [0, 7.8°]（斜率 39°/单位权重）
w > 0.25           → 线性映射到 [7.8°, 24°]（斜率 21.6°/单位权重）
```

两段在 w=0.25 处连续输出 7.8°。负权重按 |w| 映射后取符号，左右对称。
垂直映射同水平公式，端点缩放：7.8°→5.2°，24°→16°。
注：眼物理限位 ±30° 为假设值，上线前需舵机实测确认；若实际更小，S1 眼 h 上限与软件限幅同步下调。

## 三状态时间线（单轮 83–111s）

### S1 寻找 19–26s

```
聚焦 2s → 定格 0.4s → 后仰 0.3s → 失焦发散 2s
→ 左看 → 右看 → 左看(×0.7幅度) → 右看(×0.7幅度)
→ 回头落空 1.8–2.4s → 呆立 3–5s
```

- 左看 +18~+22°，右看 -18~-22°，头 yaw ±15–20°，停 1.2–1.8s
- 眼垂直目标 -2~+4°（略上）
- 第2轮幅度 ×0.7，停留 ×0.8
- 左看 roll -4~-6°、pitch -2~+2°；右看 roll +4~+6°、pitch -2~+2°
- 失焦：左眼 +1~+1.5°、右眼 -1~-1.5°，LookAt 阻尼调高，持续 1–1.5s

### S1→S2 过渡

呆立后眼先偏左上/右上，头延迟 0.3–0.6s 跟 4–8°。过渡末帧角度按 S2 基础权重反查，保证与 S2 首帧连续。

### S2 思考 52–68s

- 基础水平权重 0.30–0.40，基础垂直权重 0.20–0.30
- 微扫视 poisson(mean=4s)，幅度 0.03–0.06，80–120ms 跳
- 高潮每 15–25s 一次，峰值绝对 0.50–0.55，增量 = 峰值 − 基础，持续 0.8–1.2s，头不跟或只跟 1–2°
- 回神每 30–45s 一次

### S2→S3 过渡

S2 最后 2–3s 眼回中、头回中，再进 S3a。

### S3 恢复 12–17s

时序：S3a 闭眼 → S3b 睁眼至半睁 → S3c 完成睁眼并抬头

| 子段 | 时长 | 动作 |
|---|---|---|
| S3a 闭眼 | 4–6s | 头低-10°，Blink 0.9，每3–5s一次0.01–0.02微颤 |
| S3b 低头缓神 | 6–10s | 睁眼至半睁（Blink 0.3–0.5），眼下转 -6～-10°，水平 ±3°，慢漂移 1–2°，头仍低 -6～-8° |
| S3c 抬头 | 1.2–1.5s | 完成睁眼（0.4s）→ 停0.15s → 眼回中0.3s → 停0.2s → 抬头 |

## 中断过渡表

| 当前状态 | 中断动作 |
|---|---|
| S1 张望 | 眼回中 0.2s → 头回中 0.4s → FSM |
| S2 思考 | 眼回中 0.2s → 头回中 0.3s → FSM |
| S3a 闭眼中 | **强制睁眼 0.3s** → 眼回中 0.2s → 头抬 0.5s → FSM |
| S3b 低头睁眼 | 完成睁眼 0.3s → 眼回中 0.2s → 头抬 0.5s → FSM |
| S3c 抬头中 | 头按剩余行程抬到位（限速 15°/s，最长 0.6s）→ FSM |
| IDLE | 直接 FSM |

## 外循环

```
持续无人 >5s → preset 第1轮
→ 第1轮跑完：若仍无人 → 第2轮（S2 缩短到 35–45s，回神间隔 20–30s）
→ 第2轮跑完 → IDLE 60–120s（呼吸 + 眼1–2°微扫视 + 头0.5–1°慢漂移，每20–30s一次）
→ 仍无人 → 重回 preset 第1轮（第2轮标记重置）
→ 有人 >0.3s → 立即中断进 FSM
```
