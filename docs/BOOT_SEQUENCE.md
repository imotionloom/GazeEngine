# Boot Sequence · 开机展示编排

> 上电后 17 秒确定性脚本化编排，随后无缝交回实时人脸识别 FSM。
> 眼神语言取自真人对视时的节奏：先给观众一个可读的注视节拍，再交回实时追踪。

## 1. 设计目标

- 作品集演示开场定调：从"低头闭眼"到"直视观众"到"半垂眼回望"，15 秒内把眼颈协同、眼睑开度、眼领头随三个核心能力全部秀一遍。
- **强制完整播放**：即使摄像头前有人，编排期间不响应追踪、不被打断。
- 编排结束后自动交回 `GazeStateMachine`，进入正常交互。
- 硬件与 VRM 预览跑同一份关节指令。

## 2. 时间轴（总长 17 秒）

```
0s        2s        4s        6s        8s       10s       12s       14s       16s  17s
|--PREPARE--|-------BOOT (15秒)--------------------------------------------------|
           低头闭眼  慢睁眼   直视   眼先飘走  眼先回   半垂回望  警觉  交FSM
```

| 阶段 | 时间 | 语义 |
|---|---|---|
| PREPARE | 0.0–2.0s | 从任意姿态缓动到"低头闭眼"起点（2 秒校准） |
| SLEEPY | 2.0–3.5s | 保持低头闭眼，酝酿 |
| WAKING | 3.5–6.0s | 眼睑先慢睁，头再抬起，眼睛仍看地 |
| CONTACT | 6.0–8.5s | 眼睛抬起到前方，第一次直视锁定 |
| DAYDREAM | 8.5–11.0s | 眼睛先上瞟侧方，头 300ms 后才跟随，半垂睑 |
| RETURN | 11.0–14.0s | 眼睛先快速回中，头慢跟回，半垂眼柔软回望 |
| ALERT | 14.0–17.0s | 眼睑开到警觉位，17s 交回 FSM |

| 字段 | 含义 | 正方向 | 行程 |

## 5. 附加规则

1. **呼吸叠加**：t > 3.5 后，`body_tilt += 0.3° × sin(2π·0.2·(t-3.5))`，5 秒周期，叠加在关键帧上。
2. **编排期间不眨眼**、不触发 idle 微扫视、忽略所有 IF-1a 追踪帧。
3. **插值**：关键帧之间线性插值，P2 以 30Hz 下发；P3 的 vel_limit（颈 50°/s、眼 200°/s、睑 400°/s）作为安全上限，本编排所有速度均低于该值，不会被削。
4. **交回**：t ≥ 17.0s 后 `sample()` 返回 `None`，主循环恢复正常 FSM 处理。若此时已有面部在画面中，FSM 1–2 帧内自动进入 LOOKING；无人则自然进入 SCANNING。

## 7. 集成方式

- `p2_decision/boot_choreography.py`：关键帧表 + `BootChoreography` 类。
- `p2_decision/main.py`：`__main__` 启动时 `boot.start()`；主循环里 `if boot.is_active()` 则直接 `sample()` → `geometry_to_joints` → 下发，忽略 tracks；否则走原 FSM 链路。
- CLI：`--no-boot` 跳过编排（调试用）。
- **不改动**：presence.py / state_machine.py / idle_sequence.py / FSM / ZMQ / VRM 链路。
