# Protobuf messages

`gaze_messages.proto` is the schema for the ZMQ links between P1, P2 and P3. The generated
module `gaze_messages_pb2.py` **is committed**, so a clean clone runs without any protobuf
tooling; `p2_decision/codec.py` puts this directory on `sys.path` and imports it directly.

The renderer does **not** use protobuf: the debug stream on ZMQ 5557 carries JSON produced by
`test_harness.py`, and `tools/ws_bridge.py` forwards those bytes verbatim to the browser.

## Regenerating

Only needed when you edit the `.proto`. From the repository root:

```bash
python -m grpc_tools.protoc -Iproto --python_out=proto proto/gaze_messages.proto
```

Requirements:

- `grpcio-tools==1.85.0` (in `requirements.txt`; only needed for this step)
- The committed file was generated by protoc **7.35.1**, and it embeds a
  `ValidateProtobufRuntimeVersion` call — the installed `protobuf` must be at least that
  version or the import fails on startup. `requirements.txt` pins `protobuf==7.36.2`.
- Re-running the command above on an unmodified `.proto` reproduces the committed module byte
  for byte, so a schema change shows up as a readable diff.
- Keep the schema change and the regenerated module in the same commit. Reviewers read the
  `.proto`; the generated file is the mechanical result.

## Messages and where they travel

| Message | Link | Transport | Purpose |
|---|---|---|---|
| `PerceptionTracks` | IF-1a | ZMQ 5551, P1 → P2 | per-frame tracks: bbox, 4 anchors, distance estimate, speaking probability, identity |
| `TrackMeta` | IF-1b | ZMQ 5552, P1 → P2 | lower-rate per-track metadata: NEW/UPDATE/LOST event, ArcFace embedding, head pose |
| `SystemControl` | control | ZMQ 5553, `tools/send_control.py` → P2 | mode (AUTO/DEMO/FREEZE), speed scale, preset + anchor, recalibrate |
| `JointCmd` | IF-5 | ZMQ 5555, P2 → P3 | 11 joint angles plus `vel_limit_dps` |
| `JointState` / `FaultFlags` | IF-6 | reverse link | actual joint feedback and overtemp/stall flags — no producer in this repo |
| `Heartbeat` | — | ZMQ 5560, P2 | liveness for an external supervisor |
| `Intent`, `GazeTarget`, `JointTargetRaw` | internal | — | intermediate stages inside P2, useful if you split the engine across processes |
| `CameraFrameMeta`, `AnchorPx`, `FaceAnchors`, `DistanceEst`, `Vec3Deg`, `PresetAnchorDeg`, `EventOverride`, `ScanDirDeg` | — | — | shared sub-messages |

Field-level documentation lives in the `.proto` comments, which is the single source of truth —
this table exists only to say which message belongs to which wire.
